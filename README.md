# Pharmacy Management System

A responsive pharmacy stock management web app built using:

- HTML
- CSS
- JavaScript

## Features

- Add medicines
- Sell medicines
- Inventory management
- Expiry alerts
- Daily sales reports
- Responsive modern UI
- Form validation
